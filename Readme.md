# Domino Effect
**v1.2.0**

A highly optimized, vanilla-friendly chain destruction datapack for Minecraft Java Edition.
Minecraftに一括破壊機能を追加する、シンプルで軽量なデータパックです。

## Supported Version

* Minecraft Java Edition 26.3
